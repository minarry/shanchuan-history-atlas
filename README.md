# 山河纪 · 中国历史地图

[在线体验](https://shanchuan-history-atlas.minarryli.chatgpt.site) · [事件版图演进](https://shanchuan-history-atlas.minarryli.chatgpt.site/#year=263&evolution=three-kingdoms&step=jiange) · [补天架空篇章](https://shanchuan-history-atlas.minarryli.chatgpt.site/#chapter=butian&phase=after)

可独立部署的静态历史地图。从夏商周到民国军阀时期（1928年），使用代表年代切片浏览政权版图，叠加固定地形、水系、核心行政治所、都城与城市、关键战役。支持自动播放、速度调节、上一期边界对照、搜索、地图缩放与演示模式。

## 事件驱动的版图演进 v3.6

顶部「版图演进」可逐步播放 秦并六国（9 阶段）、从魏蜀吴到晋（14 阶段）、北魏分为东西（4 阶段）、北宋收取诸国（10 阶段）、南宋末局 · 从襄阳到崖山（8 阶段）。每章采用固定视野，可点选时间节点、回看前一步疆界或查看该阶段的原典。手机上，地图与阅读条上下排列。

普通时间轴也按事件阶段绘图。直接选年将显示该年最后一项已收录变化，点开具体事件则显示当时的阶段。选「版图切片」可以核对原图。选编范围外沿用代表年代切片。

例如打开 [263 年剑阁阶段](https://shanchuan-history-atlas.minarryli.chatgpt.site/#year=263&evolution=three-kingdoms&step=jiange)，向前播放可以看到绵竹失守、成都受降。领地交接的动画只作用于有据可查的地区；进军和局部战斗以地点表示。承接国号时沿用原有疆域。几何边缘取自粗尺度切片，所示日期是史料节点，地区接收可能延续更长时间。

在 `content/political-changes.json` 维护章节、时间、领地单元、前后归属、关联事件和史料。使用 Python 3 与 Shapely 2 运行 `npm run build:evolution`，生成 `dist/data/political-changes.json`。编译时逐步检查各地归属互斥、面积覆盖和几何有效性。

## 本地运行

需要 Node.js（无需安装 npm 依赖）：

```sh
npm run dev
```

打开终端显示的 http://127.0.0.1:4173 。不要直接双击 HTML：浏览器对 file:// 的 JSON 读取存在限制。页面运行所需地形、矢量数据及 Leaflet 均已随项目保存，运行时不依赖在线地图或第三方 CDN。

## 分层结构

| 路径 | 内容 | 时间规则 |
| --- | --- | --- |
| `dist/assets/terrain.webp` | Natural Earth 阴影地形，4800×3120，65°—145°E、8°—60°N | 固定 |
| `dist/data/rivers.geojson`, `lakes.geojson` | Natural Earth 现代河流、湖泊 | 固定 |
| `dist/data/geography.json` | 山脉、盆地、关隘、概略通道与解释 | 固定地形关系，关名作定位参考 |
| `dist/data/snapshots.json` | 政权和一级政区独立 GeoJSON、切片年代、来源与精度说明；以 geometries 字典去重 | 按代表年代切换 |
| `dist/data/cities.json` | 都城、城市、州郡治所；kind=capital/city/seat | start ≤ 年份 ≤ end |
| `dist/data/events.json` | 战役独立年份、位置、结果与地形分析 | 按相邻切片中点范围筛选，可查看全部 |
| `dist/data/research.json` | 政治制度与外交节点、逐条参考来源、通史书目、主题串读 | 独立事件纪年，不改变政治多边形 |
| `content/ancient.json`、`medieval.json`、`modern.json` | 分时代维护的战役与历史节点原稿 | `npm run build:content` 生成展示数据 |
| `dist/app.js`, `style.css` | 交互与表现 | 与数据层独立 |

## 补天 · 独立架空篇章 v3.4

历史分期栏的最末尾新增“补天 · 架空”，右端也有固定入口。真实历史仍截止1928年；补天使用“瓜分前／瓜分后”相对阶段，不绑定虚构公元年份。可通过 `#chapter=butian&phase=after` 直达。

六方势力由汉末189—195年的概略政治几何改编：凉州黎族属金；南匈奴、幽州和辽东为妖族火行；冀州与兖豫为人族火部；益州与交州为灵族木行；江东为人族水部；长安及原荆州为土族。妖族和人族火部同属火但不是同一势力。

“水火分荆”暂作事件名称。前后版图沿已有现代长江水系进行几何切割：原荆州江北归人族火部、江南归人族水部，土族退守长安。旧荆州虚线保留；土族退守地盘以双边、斜线纹理和专属说明突出。其他族群的边界保持不变。事件原因、人物与年序留待后续创作。

黎族西南缘按架空要求补至昆仑门户；这部分为明确注明的创作边界，不能当作汉末版图。幽冥鬼域以异界节点和紫色虚线表达通道关系。主角出生地参考用户示意图放在黎族、土族交界附近，标为暂定位置。

点击势力、城镇或门户可打开阅读面板；支持搜索、瓜分前后切换、旧疆对照与固定视野播放变化。历史菜单和“返回历史”恢复原历史年份与视野；历史导览和历史检索数据不混入架空内容。保留原版柔和地形。

设定原稿在 `content/butian.json`；`scripts/build-butian.py` 使用 Shapely 2.x 生成 `dist/data/butian.json`，运行时无额外依赖。修改原稿后安装 Python 3 与 Shapely，执行 `npm run build:butian`。脚本检查河流拼接、荆州覆盖完整性、无重叠分割和各方多边形有效性；常规检查验证架空纪年隔离、六方五行对应、江北江南归属及长安退守。

## 内容驱动的历史导览 v3.2

顶部「演示模式」提供四种路线：

- **通史精选**：13章、43个事件，共54幕，标准节奏约7分钟。大多数事件只用一幕合并讲述局势与影响；仅官渡、赤壁、淝水、襄樊、山海关五处增加地理细读。选定五个转折段落进行真实切片对照，不固定每章开场、每事件三幕、每章回看。
- **关键版图**：精选37幅转折切片，约3分42秒。保持同一个全图视角，让版图变化成为观看重点；全部205幅切片仍可通过普通时间轴的「版图切片」浏览。
- **当前时期**：保留本分段全部事件及同年节点，通常一事一幕。没有独立事件时只简看一幅已有版图。
- **专题线索**：沿11个主题按年代串读。

每幕按实际文字与地理节点数量分配6–14.5秒，支持调速、暂停、逐幕、目录跳转、循环和固定镜头。调速保留当前幕与已读进度，不重新拍一遍镜头。「从当前年份附近」直接进入不早于当前年份的内容，不倒回章节起点。

相邻事件若位于同一区域，共用预先计算的固定视野，地理细读沿用同一镜头。跨区域采用0.28秒淡切和直接重新构图，取消自动横向飞行；全图对照保持稳定尺度。只有主动点击地理节点才进一步细看，并暂停播放。拖动、缩放地图、滚动阅读卡片均暂停；继续或「回到镜头」可恢复叙事视野。手机阅读卡片预留固定高度，文字变化不触发地图偏移；支持系统减少动态效果偏好。

事件纪年与实际版图年份分别标注；只有真实切片存在变化时进行全图对照。不插值补造战后疆界，不把多年间全部差异归因于单一事件。

编排、区域镜头规划、阅读时长与时钟位于 `dist/tour-script.js`，播放器位于 `dist/tour-player.js`，地图执行在 `app.js`。测试覆盖各路线年代、事件完整性、对照变化、区域包含关系、同区镜头复用、调速保持当前幕、退出与计时取消。

## 地图与事件阅读 v3.1

普通浏览默认展开全宽地图，顶部压缩为56像素，底部常用时间轴从318像素缩为202像素；还可收成只保留播放和历史分期的窄栏。地图概要卡显示当前年代、实际政治底图及本期事件入口。详细选年、跨度、密集时段与速度设置集中在「时间工具」，图例可收起。

点击地图、时间轴或事件列表，统一打开右侧阅读面板，标题与关闭按钮固定可见；事件可按背景、地理、过程、影响和史料快速定位。新事件从正文开头展示，关闭后地图恢复全宽。手机使用底部阅读面板，可扩大为阅读视图，战区镜头避开面板与地图控件。演示模式的完整事件入口也使用同一面板。

时间轴默认「智能间距」：以已收录事件附近的年代为重点，将较长的空疏区间压缩为斜纹段，标出跨度，点击可切换等距查看该区间。所有年代仍可选，顺序、同年事件和公元前后纪年不变；政治底图继续按真实切片规则选择。「按年等距」可随时恢复线性时间比例，版图模式则以切片日期作为间距依据。压缩仅反映项目的收录密度，不表示这段历史没有发生事件。

进入页面先显示当前细分历史时期，避免默认展开大片无关年代；完全没有条目的窗口提供前往相邻事件和只看版图的入口。年份与像素坐标的双向映射、无公元0年、同年多条保留及空区间回退纳入自动检查。

## 精度与边界

- 不提供逐年精确国界；时间轴可以逐年选取，政治地图仍采用不晚于所选年份的最近代表切片。不存在公元0年。
- 早期活动范围、影响范围与粗尺度历史政权边界属于教育性示意。不能将色块等同于现代主权国界，也不能据此断定所有边缘地区都被持续直接统治。
- **行政层包含一级政区示意边界（州、道、路、省等），以及核心州郡治所点位。** 完整府州县多边形仍需要逐期补充和校勘。没有把现代省界伪装成历史行政边界。
- 现代地形和水系固定不变。黄河历史改道、湖泊消长、古海岸线差异未复原。NE 原始地形约公里级，放大不会产生新的地形精度。
- 战役点为大致战区；地理通道为解释性连线，不是实测道路或精确军队路线。地形是战争条件之一，并非决定论。
- 点位上的历史关名用于定位地理要地，并不代表同名关城在各个年代均已建造。

## 数据来源与许可

Natural Earth 栅格与矢量数据属于公有领域：<https://www.naturalearthdata.com/about/terms-of-use/>。阴影地形源：<https://naturalearth.s3.amazonaws.com/10m_raster/SR_HR.zip>；河流、湖泊、陆地矢量来自 Natural Earth 官方维护者的公开仓库。地形制作脚本为 `scripts/build-terrain.py`，需要 Pillow；运行产物已包含在 dist。

政权与一级政区数据选自江山时序 Jiangshan Atlas（DeanChensj）允许再分发的 GPL-3.0 图层，未导出 prefecture 层；源图层为概括示意，部分早期一级政区来源记录不完整。过滤了未经本项目校勘的通用周边政权层。当前收录 205 个代表切片，geometryRef 指向统一几何字典。具体来源版本见 dist/data/provenance.json。

历史数据来源、许可及加工限制详见 `dist/data/README.md` 与 `snapshots.json` 的 sources 字段。页面内“资料与说明”展示用户应知的数据限制和原始链接。CHGIS 未被打包；可作为未来取得适用授权并核查许可后的精确行政数据候选。

地理解释参考北京大学考古文博学院蜀道研究、中国科学院地球环境研究所河西走廊科普、河北省文物局太行古陉调查。具体链接见 `geography.json`。

## 验证与扩展

```sh
npm run check
```

修改内容原稿后，先执行 `npm run build:content`，再执行上述检查。`node scripts/package-source.mjs` 更新页面中的源码下载包。扩充内容检查覆盖范围内原34条ID保留、每场解释字段与阶段、地理坐标、来源引用、主题关联、同年多事件及「底图不晚于事件」规则。

验证覆盖时间顺序、坐标范围、政治多边形、事件解释、城市有效期与本地资源完整性。新切片沿用现有 JSON schema 即可纳入时间轴；后续适宜补充经校勘的州郡辖界 GeoJSON、古水系、战役过程与局部高分辨率 DEM。
